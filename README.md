# 🐼 Kaggle Pandas Learning

Repositorio dedicado a documentar mi aprendizaje, ejercicios prácticos y notas conceptuales del curso interactivo de **Pandas** en [Kaggle Learn](https://www.kaggle.com/learn/pandas).

---

## 🎯 Objetivo

Dominar la manipulación, limpieza y exploración estructurada de datos en Python utilizando la librería Pandas, manteniendo un registro versionado de cada lección y práctica para futuras consultas.

---

## 📂 Estructura del Repositorio

```text
kaggle_pandas_learning/
├── data/               # Datasets utilizados en los ejercicios (excluidos en Git)
├── notebooks/          # Notebooks de Jupyter (.ipynb) con las prácticas de Kaggle
├── notes/              # Apuntes teóricos y síntesis conceptual en Markdown (.md)
├── .gitignore          # Reglas para excluir archivos temporales y datos pesados
├── requirements.txt    # Registro de librerías y dependencias
